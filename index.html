SolidExpress

An excellent, open-source parametric solid modeling solution — real B-rep solids, a modern UI, and AI-ready document context.

Download source Build & run

Intent

SolidExpress aims to be a capable, approachable CAD you can study and extend — OCCT for B-rep solids, Godot for UI, PlaneGCS for sketch constraints. Export AI Context so assistants understand your parametric model.

Today: source-only from GitHub (make build, make run). Ready-to-run distributions coming soon

Roadmap

From plan docs — not all shipped yet.

  • [x] 2.2 SolverBackend seam (`sx/solver.hpp`) + PlaneGCS backend (DogLeg, diagnostics: dofs/conflicting/redundant) — AI-first backend plugs in here later
  • PlaneGCS builds as `libplanegcs.so` (LGPL dynamic-link compliance); not yet consumed by sxkernel (Phase 2)
  • **Approved dependencies:** OCCT (LGPL+exception), PlaneGCS (LGPL-2.1+), godot-cpp (MIT), Eigen (MPL-2.0), nlohmann/json (MIT), spdlog (MIT), Catch2 (BSL-1.0), libzip (BSD), Clipper2 (BSL-1.0), Embree if needed later (Apache-2.0).
  • **Golden models**: `tests/golden/*.sxp` + expected-values JSON; every phase adds its exit-criteria model here. Goldens are regenerated only by an explicit, reviewed task.
  • Happy-path first (per instruction); edge-case tests accumulate opportunistically but never block a phase gate.
  • Assembly: multi-body assemblies, explode, interference
  • Drawings: PDF/DXF, GD&T, BOM balloons, sheet-metal flats on drawings
  • Interop: AP242/XCAF, 3MF/glTF, mesh healing (DWG deferred)
  • Surfacing, sheet metal, frames, weld beads
  • PMI/MBD, ray-trace stills, turntable video, kinematic motion
  • JSON-RPC/CLI, selection queries, AI IntentConstraint solver, plugins
  • Shift-for-square rectangles; outer boundary union of closed profiles on one plane
  • Friendliness phases 21–27; optional Whisper STT in voice builds
  • Ready-to-run Linux/macOS/Windows distributions
